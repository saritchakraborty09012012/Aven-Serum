# AVEN Serum

A scroll-scrubbed product film and shop experience for **AVEN**, a blood-orange vitamin C serum. Built as a faithful React recreation of the Ascanta Studio / Ámbar site.

## Stack

- **React 18 + Vite 6** — application shell and components
- **Tailwind CSS** (preflight disabled) + hand-written design system in `src/index.css`
- **Lenis** — smooth scrolling
- **Three.js** — interactive Blender-built dropper bottle
- **Blender 5** — procedural bottle model and poster render
- **Node scripts** — asset download, frame packing, and preview atlas generation

## Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`. Production build:

```bash
npm run build
npm run preview
```

## Scroll film

The opening film is a 1,713-frame desktop sequence and a 1,046-frame portrait sequence. Progress is mapped through `src/data/framemap.json`. Full-resolution frames are loaded on demand by a prioritized, bounded queue, so fast wheel flicks never flood the browser with hundreds of image requests.

The engine in `src/components/ScrollFilm.jsx`:

- renders the film full-screen on a canvas
- requests frames around the playhead, biased towards the scroll direction, with a small in-flight limit
- spaces requests out while scrolling fast (the screen cannot show every frame anyway) and fills the gaps back in when the scroll settles
- cancels queued requests from the old direction on a reversal, so the frames needed next are not stuck behind stale downloads
- keeps a rolling cache of sharp frames near both the playhead and the frame currently on screen, and retries transient load failures instead of blacklisting a frame
- only ever advances the picture in the direction of travel. A late image finishing on the other side of the playhead can no longer flash an older frame between newer ones when the scroll reverses.
- uses preview atlases only before the first sharp frame has painted; during scrolling and anchor jumps it holds the last full-resolution frame instead of showing a soft image
- chooses the portrait or desktop sequence at load based on aspect ratio
- coordinates the chapter typography, navigation anchors, loader, and progress bar

`window.__ambarFilm` exposes `scrollToAnchor`, `scrollToProgress`, `getProgress`, `getFrame`, `getTier`, `getStats`, `startTrace`, `stopTrace`, `isReady`, and `lenis` for QA.

## Responsive

The layout adapts from 320 px phones up to desktop:

- **portrait phones** (`max-aspect-ratio: 85/100`) use the 1,046-frame portrait sequence and full-width beat copy; the nav collapses to brand + bag + Shop, and the scroll hint is dropped
- **short landscape phones** (`orientation: landscape` and `max-height: 540px`) hide the nav links, widen the beat columns, and shrink the type so the copy never sits under the pill
- **touch devices** (`pointer: coarse`) get larger hit areas without changing the design: nav brand, footer links, text links, bag quantity steppers, close buttons — and 16 px checkout fields, which stops iOS Safari auto-zooming on focus
- safe-area insets (`env(safe-area-inset-*)`) pad the footer, the bag sidebar, and the checkout panel on notched devices
- the page never scrolls horizontally: verified at 320, 360, 390, 412, 667, 768 and 844 px

## Shop and cart

The shop uses the original catalogue imagery, product data attributes, and the local checkout demo. `public/checkout.js` is injected after React mounts and manages the bag and checkout overlay. No payment is taken.

## 3D bottle

`BottleViewer.jsx` opens a Three.js studio scene from the **View in 3D** button in the product card. The model is `public/models/ambar-bottle.glb`, generated by:

```bash
npm run assets:bottle
```

The Blender source lives in `assets/blender/ambar-bottle.blend`, with the procedural build script in `scripts/blender/build_bottle.py`. It exports an amber glass shell, serum, glass pipette, cream collar, and silicone bulb. Materials are adapted in the browser for screen-space transmission and warm studio lighting.

## Asset pipeline

- `npm run assets:download` — desktop frame packs, fonts, catalogue art, frame map
- `npm run assets:download:portrait` — mobile frame packs
- `npm run assets:previews` — desktop preview atlases
- `npm run assets:previews:portrait` — portrait preview atlases

The generated sequences live under `public/frames`, `public/frames-portrait`, `public/previews`, and `public/previews-portrait`.
